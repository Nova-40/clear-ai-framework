# Acknowledgements

CLEAR - Context, Limits, Evidence, Action, Review - was created by Geoff Webster as a practical framework for reliable human-AI collaboration.

## Lineage

CLEAR replaces and develops ideas first explored in **IHORF**, an earlier framework concerned with decision quality, evidence, challenge, communication, governance, and continuous improvement.

The framework was substantially refined through iterative work on **Magpie**, a local AI/orchestration project exploring:

- persistent context;
- identity and project state;
- capability boundaries;
- local and external model interaction;
- anti-sycophancy;
- structured results;
- controlled action; and
- compatibility between different model and tool interfaces.

That work exposed a broader need for a compact, vendor-neutral protocol that could be used with systems such as ChatGPT, Claude, Copilot, local language models, and agentic platforms.

CLEAR is the result.

## Human-AI development

The framework was developed through iterative human-AI collaboration.

AI systems were used as analytical, drafting, testing, and critique tools during development. The framework's authorship, governing choices, selection of principles, and publication decision remain attributable to Geoff Webster.
