# clear-ai-framework
CLEAR (Context, Limits, Evidence, Action, Review) is a vendor-neutral framework for reliable human–AI collaboration. It defines how AI systems should handle context, capabilities, uncertainty, actions, evidence and review across ChatGPT, Claude, Copilot, local models and agents.
